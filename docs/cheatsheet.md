# Шпаргалка: от пустого файла до коммита

## Порядок работы с новой программой

### Создание
1. В VS Code: Explorer → **New File** → имя с расширением `.cpp` (например, `day4_test.cpp`).
2. Напечатать код руками.
3. Сохранить: **Ctrl + S**.

### Сборка (компиляция)
4. Файл открыт, курсор в нём.
5. **Ctrl + Shift + B**.
6. Читать терминал сборки:
   - красный текст с `error`: читать номер строки и сообщение, исправить, снова **Ctrl + S** и **Ctrl + Shift + B**;
   - ошибок нет: `.exe` создан.
7. Любая клавиша: терминал сборки закроется.

### Запуск
8. Новый терминал: **Ctrl + `**.
9. Ввести `.\имя_файла.exe` (точка и обратный слеш обязательны; **Tab** дописывает имя).
10. Если программа ждёт ввода: ввести данные и Enter.

### Проверка
11. Результат совпал с ожидаемым? Если нет, искать ошибку в логике (отладка: **F5**, **F10**).

### Сохранение работы
12. GitHub Desktop: Summary (`feat: ...`) → **Commit to main** → **Push origin**.

**Коротко:** напечатала → сохранила → собрала → запустила → проверила → закоммитила.

## Частые ловушки
- Не сохранён файл (**Ctrl + S**): собирается старая версия.
- Открыт не тот файл: сборка берёт активную вкладку.
- Сборка упала, а запустился старый `.exe`: перед запуском смотреть на терминал сборки. Перед экспериментами удалять старый файл: `del .\имя_файла.exe`.
- Нет точки в `.\имя_файла.exe`: PowerShell пишет «not recognized».
- Комментарий `//` перенёсся на новую строку без `//`: ошибка сборки.

## Горячие клавиши
| Действие | Клавиши |
|---|---|
| Сохранить | Ctrl + S |
| Собрать | Ctrl + Shift + B |
| Терминал | Ctrl + ` |
| Отладка | F5 |
| Шаг | F10 |
| Зайти в функцию | F11 |
| Остановить отладку | Shift + F5 |
| Палитра команд | Ctrl + Shift + P |

## Как читать ошибку компилятора
`файл:строка:столбец: error: сообщение`
1. Найти **номер строки** и перейти к ней.
2. Прочитать сообщение, особенно подсказку `did you mean ...`.
3. Если непонятно, посмотреть **строку выше**: пропущенная `;` обнаруживается на следующей строке.
4. Исправить **одну** ошибку, пересобрать, смотреть, что осталось (одна ошибка часто порождает несколько сообщений).

## Команды терминала
| Что сделать | Команда |
|---|---|
| Запустить программу | `.\имя.exe` |
| Удалить старый exe | `del .\имя.exe` |
| Показать файлы в папке | `dir` |
| Версия компилятора | `g++ --version` |
| Версия Git | `git --version` |
